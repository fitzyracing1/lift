lift

Treat the open internet (or any URL) as an ai::Model

The same uniform interface from focus, now pointed at the whole web.

ai::create_internet() or pass any https://... and it becomes a Model you can infer() against.

Download internet-as-model.hpp

Usage

#include "internet-as-model.hpp"
#include <iostream>

int main() {
    auto net  = ai::create_internet();                       // whole internet
    auto site = ai::create_internet("https://example.com");  // specific URL

    std::cout << net->infer("summarize the current state of X") << std::endl;
}
